# Legacy

Этот каталог содержит конфигурационные файлы, которые больше не используются напрямую.

## Caddyfile

Маршрутизация трафика теперь управляется глобальным Caddy на `/opt/caddy/`. Исходник конфигурации этого проекта — `deploy/caddy.conf.caddy`, он применяется в `/opt/caddy/conf.d/dacha.caddy` командой `just caddy-route` (через Ansible-репозиторий gazon1/Caddy-vps). Деплой приложения (`just prod-deploy` или CI) маршрут не меняет; CI только проверяет, что применённый сниппет совпадает с репозиторием, и останавливает деплой при расхождении.

Не монтируйте этот файл в docker-compose — это сломает разделяемую инфраструктуру Caddy.
