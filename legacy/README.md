# Legacy

Этот каталог содержит конфигурационные файлы, которые больше не используются напрямую.

## Caddyfile

Маршрутизация трафика теперь управляется глобальным Caddy на `/opt/caddy/`. Актуальный конфиг для этого проекта живёт в `/opt/caddy/conf.d/dacha.caddy` и обновляется автоматически при деплое (`just prod-deploy-caddy`).

Не монтируйте этот файл в docker-compose — это сломает разделяемую инфраструктуру Caddy.
